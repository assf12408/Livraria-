Livraria

Sobre o projeto

Este projeto organiza informações sobre livros.

Informações dos livros

- Título
- Autor
- Ano de publicação

Objetivo

Facilitar a organização e a consulta de livros.# Livraria-

Como cadastrar um livro

Cada livro deve conter título, nome do autor e ano de publicação.

Essas informações ajudam a identificar e organizar os livros.
Exemplo de livro

- Título: Dom Casmurro
- Autor: Machado de Assis
- Ano de publicação: 1899

- Como consultar os livros

Para encontrar as informações de um livro, consulte seu título, autor e ano de publicação. Esses dados ajudam a identificar cada obra e facilitam a organização da biblioteca.
